# Willow

Starter farmer outline for a Stardew-like 16×32 character.

## Pull this locally

The files to import into desktop software live in this folder:

- `sprite.json` — grid, palette, animations, and metadata
- `outline.svg` — idle-down preview generated from the JSON

## Suggested paint pass

When this moves from outline to final, add palette keys for skin, hat straw, hair, shirt, overalls, and boots, then replace interior `.` cells with those keys. Keep `#` as the 1px outline.
